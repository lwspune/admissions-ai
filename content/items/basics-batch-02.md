# Basics batch 02 — for admits to Class 7 — 14 items

**Date:** 2026-11-15
**Status:** for review. Promoted with `npm run items:seed -- --live --file basics-batch-02.json`
once signed off.
**Composition:** science 10 (4 easy, 2 moderate, 4 difficult), English 4 difficult. One numeric.
Every item: `part: basics`, `taught_in: 6`, so every admit from class 7 up can draw them.

## Why these, and the nine items that moved to class 7

An admit to class 7 draws basics tagged up to class 6. Until now a 6 meant "open to every admit"
(then classes 8–12), and the class 6 items had never been read as by a child who has just finished
class 6. Read that way, nine of them are beyond that child, and are now tagged 7. That changes
nothing for admits to classes 8–12, who draw everything up to 7.

| Ref | Why it is class 7 |
|---|---|
| S-E-11 | Shadows and light travelling straight: *Curiosity* 7, not 6, in the new books |
| M-E-25 | 2.5 litres in millilitres: decimals are *Ganita Prakash* 7 |
| S-E-12 | 0.05 ml drops: decimals again |
| E-D-21, E-D-22, E-D-23, E-D-36, E-D-38 | Weakening an argument, best-supported conclusion, tone, sampling: critical reasoning past an 11-year-old |
| E-D-44 | "Hardly had … than": a class 9–10 construction |

That left class 7 with 3 easy, 2 moderate and 0 difficult science basics, and 3 difficult English.
This batch fills those gaps: with it, class 7 can draw science 7 / 4 / 4 and English 19 / 10 / 7.

## The keys

S-D-44 (500 turns) was recomputed in code. The other 13 need a reader. Keys: science A 2 · B 2 ·
C 3 · D 2 (one numeric); English A 1 · B 1 · C 1 · D 1.

  chapter on water's states; if you think it is class 7 or 8, say so and it moves.
